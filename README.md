## 👋 About Me

10년차 프론트엔드 개발자로서 웹 에이전시부터 메시징 서비스, 커머스, 게임 플랫폼까지 다양한 제품을 개발했습니다. 서비스의 목적과 사용자의 흐름을 이해하고, 기획과 설계 단계부터 참여하여 발견한 문제를 해결까지 책임지는 방식으로 일합니다.

여러 프로젝트를 동시에 진행해야 할 때에는 개별 기능보다 재사용 가능한 기반을 먼저 설계합니다. 필요에 따라 백엔드 API와 데이터 구조를 함께 검토하고, 배포 환경까지 개선하여 팀이 안정적으로 제품을 운영할 수 있는 구조를 만듭니다.

## 🌱 How I Work

- **문제를 끝까지 해결합니다.** 요구사항을 구현하는 데 그치지 않고, 서비스의 목적과 실제 사용 흐름을 파악하여 필요한 개선을 제안합니다.
- **반복 가능한 기반을 만듭니다.** 공통 컴포넌트, 모노레포, 테스트와 배포 환경을 정비하여 팀이 안정적으로 개발할 수 있도록 지원합니다.
- **동료의 시간을 절약합니다.** 수동 리포트와 전시 제작처럼 반복되는 업무를 제품 기능으로 전환합니다.
- **현실적인 대안을 제시합니다.** 구현이 어려운 요청에도 의도를 먼저 확인하고, 제약 안에서 목표에 가까운 해결책을 함께 찾습니다.
- **기술을 점진적으로 개선합니다.** 팀의 학습 비용과 서비스 안정성을 고려하면서 레거시 환경을 현대화합니다.

## 🖥️ Portfolio Project

이 저장소는 경력과 주요 프로젝트를 소개하는 Next.js 기반 포트폴리오입니다. 라이트·다크 테마, 반응형 UI, 스크롤 애니메이션을 지원하며 `prefers-reduced-motion` 환경에서는 애니메이션을 제한합니다.

```bash
npm install
npm run dev
```

| 명령어                 | 설명                          |
| :--------------------- | :---------------------------- |
| `npm run dev`          | 로컬 개발 서버를 실행합니다.  |
| `npm run build`        | 배포용 결과물을 생성합니다.   |
| `npm run lint`         | TypeScript 타입을 검사합니다. |
| `npm run format:check` | 코드 서식을 검사합니다.       |

프로젝트와 경력 데이터는 `data/portfolio.ts`에서 관리하며, 화면 구성 요소는 `components/portfolio/`에 있습니다.
