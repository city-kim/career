## 👋 About Me

웹 에이전시에서 개발을 시작했습니다. 이후 알리고에서 문자·카카오톡 발송 서비스를 운영했고, 프레시지에서는 쇼핑몰과 사내 시스템을 개발했습니다. 보이저에서는 프론트엔드를 혼자 맡아 웹사이트와 게임 운영 도구를 만들었습니다.

## 🖥️ Portfolio Project

이 저장소는 경력과 주요 프로젝트를 소개하는 Next.js 기반 포트폴리오입니다. 라이트·다크 테마, 반응형 UI, 스크롤 애니메이션을 지원하며 `prefers-reduced-motion` 환경에서는 애니메이션을 제한합니다.

```bash
npm install
npm run dev
```

| 명령어                 | 설명                          |
| :--------------------- | :---------------------------- |
| `npm run dev`          | 로컬 개발 서버를 실행합니다.  |
| `npm run build`        | 배포용 결과물을 생성합니다.   |
| `npm run lint`         | TypeScript 타입을 검사합니다. |
| `npm run format:check` | 코드 서식을 검사합니다.       |

프로젝트와 경력 데이터는 `data/portfolio.ts`, 대표 사례는 `data/case-studies.ts`에서 관리합니다. 화면 구성 요소는 `components/portfolio/`에 있습니다. 각 프로젝트는 `app/projects/[slug]/page.tsx`에서 정적 페이지로 생성되며, GitHub Pages의 `/career` 경로를 지원합니다.

사실 확인 기준과 이력서 업로드 등 후속 작업은 `docs/project-sources.md`에 기록합니다. 이력서와 신규 외부 패키지 링크는 아직 연결하지 않았습니다.
